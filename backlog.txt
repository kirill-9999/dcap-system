Обработка архивов
1. Раскрываем архивы на 1 уровень. Архивы в архиве не обрабатываем, записываем как ошибки обработки
2. Различаем поврежденные архивы и архивы под паролем. Для архива под паролем записываем событие безопасности
3. Файлы и папки внутри архива обрабатываем по общим правилам. При записи имя архива фиксируем как папку

Распределенная система DCAP
1. Агент сканирования (Scanner)
2. Агент управления (Manager)
3. Веб-интерфейс управления (WebUI)
4. БД (DB)

Функционал агента управления:
1. Ведет в БД список агентов сканирования
2. Ведет в БД список ресурсов, для которых нужно провести сканирование
4. Ведет систему расписаний. Есть стандартное время сканирования. И для каждого ресурса можно задать индивидуальное время сканирования. Задания назначаются агентам в соответствии с этим расписанием. 
3. Опрашивает агентов, проверяет статус
4. Если агент свободен, передает ему задание на сканирование. Задание передает порциями от имеющегося списка ресурсов c учетом stete 
5. state должен периодически пересматриваться, файлы должны сканироваться повторно.
6. Принимает от агентов state, события безопасности, каталог.
7. Сохраняет их в БД
8. Взаимодействует только с агентами их своего списка.


Функционал Агента сканирования
Функционал.
1. Агент запускается и ждет обращенией от агента управления
2. Отвечает на обращения агента управления
3. При первом обращении передает ему всю информацию, которая не была передана в предыдущий запуск
4. При получении задания на сканирование выполняет задание.
5. Периодически вызывает агент управления, передает ему state, события безопасности, каталог, свой статус, список файлов, которые не смог обработать. Аналогично - по завершении задания на сканирование
6. Если агент управления недоступен, сохраняет state, события безопасности, каталог у себя, передает при следующих успешных подключениях
7. По завершении обработки передает Агенту управлегия статус, перезапускается, очищает память, ждет следующего задания
8. При останове - сообщает статус Агенту управления
9. Агент управления настроен в настроечном файле. Взаимодействие осуществляется только со своим агентом управления

Веб-интерфейс управления
1. Управление списком ресурсов для сканирования (файловые, S3 minio)
2. Управление списком агентов. Просмотр их текущего статуса
3. Просмотр каталога
4. Управление расписанием агентов
5. Управление размером задания

БД для Хранения:
1. каталог
2. state
3. Настройки
4. Расписания

По системе в целом.
1. Система распределенная
2. В любой момент времени возможен останов / недоступность /повторный запуск любого компонента
3. Агентов может быть много. Вся система рассчитана на обработку миллионов файлов
4. Взаимодействия асинхронные.
4. Для всех взаимодействий обеспечивается взаимная аутентификация сторон. 
5. Для сообщений обеспечивается целостность и конфиденциальность. 
6. Обеспечить безопасное хранение аутентификационной информации для доступа к хранилищам
7. Провести red teaming, SAST, SCA
