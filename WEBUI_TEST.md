# Ручное тестирование WebUI (День 14)

Страница «Управление доступом» реализована в `webui/main.py` (инлайн HTML+JS) и работает
на WebUI-сервере `:8001`. Эндпоинты `/api/access/*` — в `webui/api/routes.py` (читают
`manager/src/db/dcap.db` напрямую).

## Проверка страницы «Управление доступом»

### Шаг 1: Запуск

```powershell
# Терминал 1 — Manager (и статика на :8000)
python -m uvicorn manager.src.main:app --port 8000

# Терминал 2 — WebUI (страница «Управление доступом»)
python run_webui.py
```

> Перед запуском WebUI скопируй БД: `copy manager/dcap.db manager/src/db/dcap.db`
> (см. AGENTS.md — WebUI читает `manager/src/db/dcap.db`).

### Шаг 2: Открыть страницу

WebUI: http://localhost:8001

### Шаг 3: Перейти на страницу «Управление доступом»

Кликнуть на «Управление доступом» в навигации (data-page="access").

### Шаг 4: Проверить карточки статистики

- [ ] Отображаются 4 карточки: ресурсов, записей прав, алертов, рискованных алертов
- [ ] Значения соответствуют данным БД (`manager/dcap.db`)

### Шаг 5: Вкладка «Ресурсы»

- [ ] Отображается таблица ресурсов с правами (путь, владелец, чувствительность, уровень, источник)
- [ ] У каждого ресурса есть счётчики: прав и открытых алертов
- [ ] Кнопка «Открыть права» открывает модальное окно прав ресурса
- [ ] В модальном окне отображаются записи прав (субъект, тип, право, источник, наследование)
- [ ] Фильтр по субъекту работает
- [ ] Фильтр по типу (user/group/system/...) работает
- [ ] Фильтр по праву (read/write/full_control/...) работает
- [ ] Пагинация «Назад/Вперёд» и счётчик записей работают

### Шаг 6: Вкладка «Алерты»

- [ ] Отображаются алерты (важность, тип, описание, рекомендация, статус)
- [ ] Кнопки смены статуса (Принят/Открыт/Решён/Игнорирован) работают и обновляют строку
- [ ] Фильтры по важности (critical/warning/info) работают
- [ ] Фильтры по статусу работают
- [ ] Сброс фильтров («Сбросить») работает

### Шаг 7: Общее

- [ ] Страница автообновляется (~30 сек)
- [ ] Переключение на другие страницы (Дашборд, Ресурсы, Находки, Задачи) работает
- [ ] Ошибки API показываются понятным сообщением в карточке/таблице
