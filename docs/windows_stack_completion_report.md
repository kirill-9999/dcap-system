## Ключевые решения

1. **REST вместо gRPC** — проще развертывание, проще тестирование
2. **SQLite → SQLAlchemy** — одновременный доступ Manager + WebUI
3. **wevtutil XML** — отказ от Text-вывода (русская локализация ломает парсинг)
4. **colon-syntax** — `/f:XML`, `/q:...` вместо пробельного синтаксиса
5. **Буферизация** — SQLite-буфер агента при недоступности Manager
