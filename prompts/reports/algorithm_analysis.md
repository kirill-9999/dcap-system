## 8. Возобновление задания после перезапуска

| Компонент | Как есть | Как должно быть |

| Сканер | ❌ `scanner_id` сохраняется, но **прогресс задания НЕ сохраняется**. | Linux Agent | ❌ **Нет состояния.** После рестарта — новый агент, нет отслеживания | Добавить `state.json` с `agent_id` и метками последних обработанных событий |

## 11. Graceful shutdown (приостановить, сохранить, отправить)

| Компонент | Как есть | Как должно быть |
|-----------|----------|-----------------|
| Сканер | ❌ Отправляет heartbeat "offline" (стр. 650). **Текущее задание НЕ приостанавливается, результаты НЕ сохраняются, НЕ отправляются** | 1) Приостановить задание (сохранить прогресс в `state.json`) 2) Отправить результаты в Manager 3) Отправить heartbeat "offline" 4) Закрыть соединения |
| Win Agent | ❌ `running = False` → `buffer.close()` (стр. 184). **Несобранные/неотправленные данные теряются**. Heartbeat "offline" **не отправляется** | 1) Дождаться завершения текущего цикла сбора 2) Отправить все неотправленные из буфера 3) Отправить heartbeat "offline" 4) Закрыть буфер |
| Linux Agent | ❌ Аналогично: `running = False` → `collector.stop()` → `buffer.close()` (стр. 121-127). **Нет отправки накопленного. Heartbeat "offline" не отправляется** | 1) Остановить collector 2) Отправить все неотправленные из буфера 3) Отправить heartbeat "offline" 4) Закрыть буфер |

## Async-архитектура (компоненты работают независимо)

| Компонент | Как есть | Как должно быть |
|-----------|----------|-----------------|
| Сканер | ❌ Всё синхронно в одном потоке: heartbeat → get_task → execute → submit. Неуспешный heartbeat (3 попытки) блокирует 3 сек. Executing блокирует heartbeat | Минимум 3 потока: (1) heartbeat (2) execution (3) offline-sync. Разделение состояния через общие данные с блокировками |
| Win Agent | ❌ Всё в одном потоке: heartbeat → collect → send | Минимум 2 потока: (1) heartbeat + send (2) collect. Буфер — общая SQLite с `check_same_thread=False` (уже есть) |
| Linux Agent | ⚠️ Collector в отдельном потоке (threading.Thread, стр. 90), но heartbeat и send в главном | Heartbeat + send вынести в отдельный поток |
