# Справка для архитектора — редизайн WebUI (палитра «серый · зелёный · хаки · белый · синий»)

**Дата:** 13.09.2026
**Автор:** Кодер (Big Pickle)
**Версия WebUI:** v3.12.0 (без изменения версии — только CSS/шаблоны)

## 1. Цель

Изменена цветовая палитра WebUI в соответствии с согласованным статическим макетом
(`temp/dashboard-mockup.html`). Основное: **убран жёлтый цвет** — там, где он был
(`--color-warning`), теперь **хаки**. Палитра приведена к 5 цветам.

## 2. Палитра

| Цвет | Роль | Hex (light) | Hex (dark) |
|------|------|-------------|------------|
| Серый | Фон страницы, рамки, вторичный текст, тёмные оттенки | `#f4f5f1` фон, `#2e3330` текст, `#c9cdc5` рамки | `#1b1f1c` фон, `#4a514b` рамки |
| Зелёный | Успех (success), активные состояния, онлайн | `#3e8e5a` | `#22352a` фон |
| Хаки | Warning (вместо жёлтого), secondary | `#8b8b66` | фон `#2e2e24` |
| Белый | Карточки/поверхности (surface) | `#ffffff` | `#252b27` |
| Синий | Primary (ссылки, кнопки), info | `#3a6ea5` | |

## 4. Изменённые файлы

1. `webui/static/css/variables.css` — вся палитра light + dark (единственное место, где заданы цвета).
2. `webui/templates/dashboard.html` — цвета KPI-иконок под макет:
   - Ресурсов → зелёный (success)
   - Находок → синий (primary)
   - Агентов онлайн → хаки (warning)
   - Алертов → серый (text-muted / border)
3. `temp/dashboard-mockup.html` — статический макет (в `.gitignore`, в коммит не входит).

Компонентные CSS (`components/*.css`), остальные шаблоны и JS **не менялись** — они
используют CSS-переменные и подхватывают палитру автоматически.

## 5. Проверка

```powershell
python run_all.py          # WebUI на http://127.0.0.1:8001
```

Проверить страницы: Дашборд, Каталог, Находки, Аудит, Сканеры (светлая и тёмная темы —
кнопка луны в сайдбаре). Убедиться, что предупреждения/статусы «ожидание» теперь хаки,
а не жёлтые.

## 6. Примечания

- **Красный (`--color-danger`) не убран** — он не входит в согласованную 5-цветную палитру,
  но необходим для деструктивных действий (удаление ресурсов, оффлайн-статусы, ошибки).
  Выделен отдельным пунктом для решения архитектора: при желании можно перевести на серый.
- `--color-secondary` (хаки) в светлой теме дублирует `--color-warning` — допущение
  осознанное: семантика «вторичный акцент» и «предупреждение» визуально совпадают.
- Версия релиза не менялась, миграций нет (изменения только статический CSS/шаблон).
- Для включения в релиз: при необходимости обновить `ROADMAP.md` (пункт дизайна WebUI)
  и `ARCHITECTURE.md` (раздел WebUI). Файлы архитектора не трогались.
