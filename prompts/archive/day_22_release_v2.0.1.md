# Release Notes — DCAP System v2.0.1

**Дата:** 2026-08-25
**Версия:** v2.0.1

---

## 🎯 Обзор

DCAP System v2.0.1 — это завершение Windows-стека. Система полностью готова к использованию на Windows-платформах для обнаружения и классификации персональных данных, управления доступом и аудита файловой системы.

---

## 🆕 Что нового

### 1. Управление доступом
- Модели данных: `AccessEntry`, `AccessAlert`, `PermissionChange`
- Коллекторы прав: local (icacls), remote, ad (заглушка)
- API `/api/permissions/*` (12 эндпоинтов)
- WebUI страница «Управление доступом»
- Анализ избыточных прав и наследования

### 2. Аудит файловой системы
- Легкий агент аудита (Python + requests, ~50 MB)
- Windows-служба с автозапуском
- Буферизация событий (SQLite)
- API `/api/audit/*` (5 эндпоинтов)
- WebUI страница «Аудит» с фильтрами и статистикой
- Отчеты в Excel и PDF

### 3. WebUI
- Единый каноничный интерфейс на `webui/main.py` (:8001)
- Редирект с Manager (:8000) → WebUI (:8001)
- Дашборд с блоками: ресурсы, находки, задания, сканеры, агенты аудита
- Страницы: Находки, Ресурсы, Задания, Сканеры, Доступ, Аудит

### 4. Интеграционное тестирование
- 47/48 тестов пройдено
- Покрытие: API, Scanner, Audit Agent, WebUI, E2E

## 🚀 Как запустить

```powershell
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Инициализировать БД
python init_db.py

# 3. Запустить Manager (API)
python -m uvicorn manager.src.main:app --port 8000

# 4. Запустить WebUI
python run_webui.py

# 5. Запустить Audit Agent (опционально)
cd audit-agent
python main.py

# 6. Запустить Scanner (опционально)
cd ..
python run_scanner.py
