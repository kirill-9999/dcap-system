📌 ПРОБЛЕМА

В `S3LineConnector.scan_path` (53.2) было:
```python
if parsed.netloc and parsed.netloc != self._bucket:
    logger.warning("[S3Line] Bucket в path (%s) != bucket в config (%s) — использую path", ...)
source_prefix = (parsed.path or "").lstrip("/")
Сравнение parsed.netloc != self._bucket вводит в заблуждение: мы никогда не используем parsed.netloc (bucket из path), всегда — self._bucket (из scan_config). То есть либо WARNING печатается вхолостую, либо (хуже) у читателя кода возникает ощущение, что bucket может прийти из path.

TASK-134 — s3_line_connector.py: убрать сравнение и WARNING

Найти в scan_path:

python
        source_prefix = self._prefix
        if path:
            parsed = urlparse(path)
            if parsed.scheme in ("s3", "minio"):
                if parsed.netloc and parsed.netloc != self._bucket:
                    # Bucket в path отличается от bucket в config — доверяем path.
                    logger.warning(
                        "[S3Line] Bucket в path (%s) != bucket в config (%s) — "
                        "использую path",
                        parsed.netloc, self._bucket,
                    )
                source_prefix = (parsed.path or "").lstrip("/")
            else:
                source_prefix = (path or "").lstrip("/")
Заменить на:

python
        # Bucket — всегда из scan_config.connector.s3.bucket (см. 53.1a):
        # Manager кладёт bucket в payload задачи, а path (s3://bucket/prefix)
        # используется только как suffix для префикса. Если в path указан
        # другой bucket — он игнорируется намеренно (контракт ресурса —
        # bucket фиксирован на момент создания).
        source_prefix = self._prefix
        if path:
            parsed = urlparse(path)
            if parsed.scheme in ("s3", "minio"):
                source_prefix = (parsed.path or "").lstrip("/")
            else:
                source_prefix = (path or "").lstrip("/")
Убрать неиспользуемый импорт logger.warning в этом месте — logger остаётся для других сообщений.
