## 📋 КОНТЕКСТ ПРОЕКТА

### Описание
DCAP (Data-Centric Audit and Protection) — система для обнаружения и классификации персональных данных, учетных записей и кода в файловых хранилищах.

### Версия: v2.0.0-alpha

## 🚫 ОГРАНИЧЕНИЯ

1. **Максимально использовать имеющиеся наработки** — не переписывать существующий код без необходимости
2. **Менять архитектуру только после обсуждения** — все изменения согласовывать с архитектором
3. **Не отключать имеющийся функционал** — новые фичи должны работать вместе со старыми
4. **Всегда генерировать полный код для изменяемых файлов** — не давать фрагменты
5. **Не предлагать изменений архитектуры** — только реализация по ТЗ
6. **При вариативности — выделять предпочтительный вариант** и обосновывать почему
7. Всегда предоставлять тестовый сценарий для проверки
8. Разработка ведется на OC Windows 10
